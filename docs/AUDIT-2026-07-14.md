# Site Audit — 2026-07-14

Full audit of `feat/unified-nextjs-portal` (Next.js 14 App Router). Three areas: problems, features present, features missing.

---

## A. Problems (ordered by impact)

### Performance — root causes of "slow"

1. **Entire site renders client-only.** `src/app/page.tsx:3` uses `dynamic(..., { ssr: false })` for the whole marketing page (same for `/pricing`, `/account`). Browser receives an empty shell; nothing paints until React + GSAP + Lenis + Firebase JS downloads and executes. Biggest LCP/TBT problem — bigger than the 3D itself.
2. **Firebase loads on every page.** `src/app/layout.tsx:29` wraps everything in `AuthProvider` → `firebase/auth` + `firestore` client chunks ship on the landing page which has no auth UI.
3. **Two WebGL contexts on one page.** Hero canvas (`src/three/HeroCanvas.tsx`) + particles canvas (`src/three/ParticleScene.tsx`), each with Bloom postprocessing. `ParticleScene.tsx:22` Bloom `luminanceThreshold={0.04}` — everything blooms, heaviest setting.
4. **Heavy geometry:** 22,000 particles desktop / 9,000 mobile (`ParticleScene.tsx:20`) + 4,000 more in hero (`HeroCanvas.tsx:44`) + 240×32-segment torus knot (`LoopMesh.tsx:60`). Mobile only *downscales* 3D, never disables it (`src/lib/webgl.ts:21-27`) — big GPU/battery cost on phones.
5. **3–4 always-on rAF loops:** Lenis ticker (`useSmoothScroll.ts:32-34`), custom cursor loop even when pointer idle (`Cursor.tsx:30-37`), up to 2 WebGL loops.
6. **Dead dependency:** `@react-three/drei` (2.9 MB) in package.json, zero imports.
7. **Fonts via CSS side-effect imports** (`layout.tsx:2-3`), not `next/font` — no preload, no fallback metrics → CLS on font swap.
8. `LoopMesh.tsx:50` reads `window.scrollY` every frame — forced reflow.
9. No `optimizePackageImports` in `next.config.mjs`.

### UX / UI

10. **Portal pages are dead-ends:** `/account` and `/pricing` render **no nav, no footer, no way back home** (`AccountView.tsx:130-143`, `Pricing.tsx:73-119`).
11. **Dead social links:** `Footer.tsx:39` — Twitter/GitHub/LinkedIn all `href="#"`.
12. **Fabricated stats:** `Stats.tsx:6-11` — "12,000+ learners", "1.2M loops closed", "4.9★" on a pre-launch product. Reads as untrustworthy.
13. **CTA mismatch:** all "get the app" CTAs are `mailto:` links (`Hero.tsx:86`, `CTA.tsx:28`); no email-capture form.
14. **Cancel subscription = one click, no confirm dialog** (`AccountView.tsx:104`).
15. **AuthButton returns `null` while loading** (`AuthButton.tsx:7`) → layout shift in nav.
16. Firestore `onSnapshot` has no error handler (`AccountView.tsx:43`) — errors silently show "No active subscription".
17. No shared `Button`/`Card` components — white-pill style copy-pasted 6× (`Nav.tsx:71`, `Hero.tsx:92`, `CTA.tsx:30`, …).
18. Portal pages skip the `shell` layout utility; spacing/rhythm inconsistent with marketing (`py-16` vs `py-28 sm:py-36`).

### Accessibility

19. Closed mobile menu still keyboard-focusable (`Nav.tsx:104-108` — needs `inert`/`hidden`); no focus trap when open; no skip-to-content link.
20. Custom cursor hides native cursor site-wide with no off switch (`Cursor.tsx:13`).
21. Contrast risk: body copy at `text-white/40`–`/55` likely below WCAG AA (`Footer.tsx:51`, `Concept.tsx:63`).

### Config / hygiene

22. `metadataBase` points at `impactloopapps.github.io` (`layout.tsx:10`) — wrong for Vercel domain; OG/canonical URLs broken.
23. GitHub-Pages leftovers in `public/`: `404.html` (hard-codes `/website/` base path — broken on Vercel), `.nojekyll`; stray `dist/` dir untracked.
24. Next 14 pin is load-bearing: `{ssr:false}`-in-Server-Component pattern errors in Next 15 (docs/PHASE2-PUNCHLIST.md:9).

## D. Recommendation (rewrite direction)

User is free to rewrite (no live users). Suggested approach:

1. **Kill the 3D hero** (source of slowness) → replace with lightweight CSS/SVG animated hero or a single cheap WebGL effect. Drop `three`, `@react-three/*`, `postprocessing` entirely (~35 MB deps, huge chunk).
2. **Server-render everything static**; client components only for auth widgets/checkout. Fix LCP at the root.
3. **New professional theme**, mobile-first, shared design system (Button/Card/Input primitives), light+dark.
4. **Admin dashboard** at `/admin` gated by Firebase custom claims.
5. Replace GSAP+Lenis with CSS scroll-driven animations / small IntersectionObserver reveals (or keep GSAP only where truly needed).
6. Fix hygiene: metadataBase, delete GH-Pages artifacts, sitemap/robots, real social links or remove, real stats or remove.
